Vous devez construire l'intégralité du script (Imports, Fonctions, Logique) à partir d'un nouveau Notebook.

I. Contexte & Objectifs

Vous agissez en tant qu'analyste géomaticien. Votre objectif est de développer une méthodologie reproductible permettant de quantifier des surfaces environnementales spécifiques sur deux territoires urbains distincts à partir d'imagerie satellite récente.

Le livrable attendu est un script Python capable d'automatiser la chaîne de traitement complète : de l'acquisition des données brutes à l'analyse statistique finale.

II. Paramètres d'Étude (Par Groupe)

Rappel Mathématique : La normalisation d'indice suit toujours la logique (A - B) / (A + B).

III. Cahier des Charges Technique

Votre script Python doit impérativement respecter les étapes fonctionnelles suivantes :

1. Diagramme de Flux (Flowchart)

Avant d'écrire la moindre ligne de code, dessinez le diagramme logique de votre traitement (Entrées > Processus > Sorties). [Image of flowchart diagram symbols] Ce schéma devra être présenté lors de la soutenance.

2. Module d'Acquisition Géométrique

  • Le script doit interroger l'API geo.api.gouv.fr pour récupérer dynamiquement le contour (GeoJSON) des communes ciblées.
  • Aucun fichier Shapefile ne doit être stocké localement au préalable.

3. Module de Traitement Satellite

  • Connexion à l'API Google Earth Engine.
  • Filtrage de la collection Sentinel-2 SR Harmonized sur la période Estivale 2025.
  • Application d'un filtre nuageux strict (< 10%).
  • Calcul de l'indice spectral assigné à votre groupe.
  • Export de l'image résultante au format GeoTIFF (résolution 20m).

4. Module d'Analyse Statistique (NumPy)

  • Ouverture du fichier Raster généré.
  • Lecture des métadonnées pour récupérer la résolution spatiale du pixel.
  • Utilisation de la bibliothèque NumPy pour :
    • Isoler les pixels valides.
    • Compter les pixels répondant au critère du seuil.
    • Convertir ce nombre de pixels en une surface réelle en Hectares.
  • Affichage clair des résultats dans la console.

IV. Livrables de Fin de Séance

  1. Le script Python complet (.py ou .ipynb).
  2. Le schéma méthodologique (Flowchart).
  3. Une présentation orale de 10 minutes exposant la comparaison chiffrée entre les deux villes.
